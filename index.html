แนวทางการนำไปรันบน GitHub Pages

เว็บแอปพลิเคชันนี้ถูกออกแบบด้วยสถาปัตยกรรม Static Single-Page Application (SPA) ทำให้สามารถอัปโหลดขึ้น GitHub Repository และเปิดใช้งาน GitHub Pages ได้ฟรีทันทีโดยไม่ต้องตั้งค่าฐานข้อมูลฝั่งเซิร์ฟเวอร์:

  1. สร้าง Repository ใหม่บน GitHub (เช่น thai-exam-app)
  2. บันทึกโค้ดหน้านี้เป็นไฟล์ชื่อ index.html แล้ว Commit & Push ขึ้นไปยัง Branch main
  3. ไปที่เมนู Settings → Pages ของ Repository แล้วเลือก Source เป็น Deploy from a branch (main / root)
  4. หากคุณเพิ่มข้อสอบใหม่ในหน้า "คลังข้อสอบ" คุณสามารถกดปุ่ม Export JSON เพื่อนำไฟล์ข้อสอบไปแชร์ให้เพื่อนร่วมทีม Import เข้าใช้งาน หรือนำข้อมูล JSON มาอัปเดตในโค้ดได้ทันที
